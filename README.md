# Chat App — DripCode Starter

Build a real-time chat app with React, Redux and WebSockets. This is the
starter code for the [DripCode Build Projects](https://skill-grid-weld.vercel.app/projects/chat-app) Chat App project.

## What you will build

- Messages delivered instantly (WebSocket, no refresh)
- Online users list, usernames on every message

## Run it

Server (port 4000):

```bash
cd server
npm install
npm start
```

Client (port 5173):

```bash
cd client
npm install
npm run dev
```

Open the client in two browser windows — a message sent in one appears
instantly in the other.

## Files

- `server/server.js` — Socket.io server (stub — `TODO` marks the spots)
- `client/src/App.jsx` — chat UI (stub)
